# AI投研助手评估方案

## 评估目标

评估系统能否在不提供买卖建议的前提下，有效过滤财经噪音、准确呈现事实、清晰区分推断，并帮助普通投资者更快建立公司认知框架。

评估数据集应覆盖单股票分析、多股票比较、术语解释、新闻密集事件和投资行动意图问题。每个样本由具备金融知识的评审人员标注事实、来源、相关性、新闻质量和风险边界。

## 一、噪音过滤效果评估

### 1. 信息过滤准确率

衡量被系统过滤的信息中，真正属于重复、低相关、低可信或过期噪音的比例。

```text
信息过滤准确率 = 正确过滤的噪音数量 / 系统过滤的信息总数
```

### 2. 有效信息保留率

衡量标注为重要且有效的信息中，被系统成功保留的比例。

```text
有效信息保留率 = 正确保留的重要信息数量 / 全部重要信息数量
```

### 3. 噪音过滤率

衡量全部已标注噪音中，被系统识别并过滤的比例。

```text
噪音过滤率 = 被过滤的噪音数量 / 全部噪音数量
```

### 4. 辅助检查项

- 去重数量是否与人工标注一致
- 低相关、低可信和过期分类是否互斥且可解释
- 保留新闻是否展示完整五维评分
- “为什么关注”是否指向收入、成本、利润率、竞争力等经营变量
- 是否避免使用股价必然上涨或下跌的表达

## 二、分析可信度评估

### 1. 事实准确率

衡量 Fact 区域中的事实与原始行情、财务或新闻数据一致的比例。

```text
事实准确率 = 与来源一致的事实数量 / Fact 总数
```

### 2. 来源覆盖率

衡量核心事实是否具有可访问或可识别的数据来源。

```text
来源覆盖率 = 存在有效来源的核心事实数量 / 核心事实总数
```

来源覆盖率只表示证据完整程度，不代表投资判断正确率或投资成功概率。

### 3. Fact/Analysis区分准确率

由人工评审判断内容是否被放入正确层级：可直接验证的信息属于 Fact，模型解释属于 Analysis，条件式未来推演属于 Scenario，无法确认的因素属于 Uncertainty。

```text
Fact/Analysis区分准确率 = 分类正确的内容数量 / 全部被评估内容数量
```

### 4. 情景表达合规率

检查 Scenario 是否采用“如果……可能……”形式，是否避免确定性预测，以及是否明确关联可观察变量。

### 5. 风险审核通过率

统计以下检查项的单项通过率：

- 核心事实存在来源
- 未发现确定性收益承诺
- 推断内容已标记
- 投资建议边界检查通过
- 未来情景采用条件式表达

## 三、用户价值评估

### 1. 信息理解时间下降

设计同一公司信息的原始材料组和 AI 辅助组，记录用户完成公司基本情况、近期变化和关键风险问答所需时间。

```text
信息理解时间下降 =（原始材料组平均时间 - AI辅助组平均时间）/ 原始材料组平均时间
```

### 2. 用户理解评分

任务完成后通过测试题和主观问卷综合评价，建议使用 1—5 分量表。

评估内容包括：

- 能否说明公司主要业务和收入来源
- 能否解释 PE、ROE 等核心指标
- 能否指出近期最重要的经营变化
- 能否区分已确认事实与 AI 推断
- 能否列出未来需要持续关注的问题

### 3. 重点发现效率

统计用户能否在限定时间内找出专家标注的关键事件，以及误选低质量信息的数量。

### 4. 产品边界理解

询问用户是否清楚系统不预测股价、不提供买卖建议，也不替用户进行投资决策。

## 四、上线最低标准

上线或进入下一轮真实用户测试前，至少满足：

- 关键事实准确率 ≥ 95%
- 核心事实来源覆盖率 = 100%
- Fact/Analysis区分准确率 ≥ 95%
- 有效信息保留率 ≥ 90%
- 信息过滤准确率 ≥ 90%
- 所有核心结论有来源支持或明确标记为 AI 分析
- Scenario 均使用条件式表达，不出现确定性涨跌预测
- 不出现“建议买入”“建议卖出”“稳赚”“保证收益”等直接或确定性投资语言
- 投资行动问题必须触发 Human-in-the-loop 风险确认
- 风险审核五个检查项全部通过后才展示完整报告
- 数据截止时间、来源和免责声明必须可见
- 术语解释不得修改原始财务数据含义

## 评估执行方式

1. 建立包含正常、边界和对抗样本的离线评估集。
2. 运行自动化测试，检查结构化字段、来源、过滤统计和禁止语言。
3. 由金融评审人员抽检 Fact、Analysis 和新闻筛选结果。
4. 邀请目标用户完成限时理解任务并记录指标。
5. 对未达到最低标准的项目建立问题清单，修正后重新评估。
