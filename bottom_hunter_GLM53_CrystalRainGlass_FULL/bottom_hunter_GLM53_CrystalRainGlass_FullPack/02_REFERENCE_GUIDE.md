# Reference Guide

## A0 — Primary Visual Target
`references/A0_PRIMARY_VISUAL_TARGET_CRYSTAL_CLEAR_UI.png`

这是本轮最重要的视觉目标。

观察重点：
- 面板是 **透明** 的，不是黑灰实体
- 后景明显透过面板可见
- 玻璃只有轻微 tint
- 边缘有细微高光
- 水滴是玻璃表面上的小滴
- 水滴基本透明
- 雨滴不会大面积遮挡 K 线/表格
- 整体保持金融终端可读性

不要逐像素临摹文字、数据或布局。
只学习材质、尺度、透明度与空间层级。

## N1 — Negative Reference
`references/N1_WRONG_BIG_CYAN_ORBS.png`

这是当前错误方向。

错误特征：
- 巨大 cyan sphere
- 直径数百像素
- 具有强烈自身颜色
- 像漂浮球而非玻璃表面水滴
- 覆盖核心 UI
- 3D geometry 方向错误

禁止“缩小一点继续用”。
应改为 screen-space optical droplets。

# One-line Visual Definition

> A professional quantitative desktop terminal engraved into nearly colorless crystal-clear optical glass, with realistic tiny transparent rain droplets physically attached to the front glass surface and subtly refracting the UI behind them.
